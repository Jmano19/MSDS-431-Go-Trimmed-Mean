# GenAI Tools – Development Documentation

## Tool Used

ChatGPT (OpenAI)

## Purpose

ChatGPT was used as a coding assistant during the development of the Go trimmed mean package.

## Development Activities

| Activity | How GenAI Assisted |
|---|---|
| Package design | Discussed Go modules, package structure, and reusable functions |
| Implementation | Assisted with generic numeric types and trimming logic |
| Unit testing | Suggested test cases for symmetric and asymmetric trimming |
| Error handling | Reviewed input validation and error conditions |
| Performance | Helped develop Go benchmark functions |
| Documentation | Assisted with README and usage examples |

## Human Review and Validation

All generated code was reviewed and executed in the local development environment.

The developer independently ran Go unit tests, measured test coverage, performed static analysis, built the package, and executed performance benchmarks.
